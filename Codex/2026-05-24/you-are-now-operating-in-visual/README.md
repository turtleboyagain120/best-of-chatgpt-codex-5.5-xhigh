# Vanta Lyric

An interactive zero-build prototype of a cinematic future operating environment.

## Run

```powershell
node .\server.mjs
```

Then open:

```text
http://localhost:5173
```

## Prototype Features

- Reactive Three.js Lyric Field with procedural constellations, signal weather, orbiting agents, and causal link rendering.
- Full-screen command interface with Future Loom, Agent Theater, Signal Weather, Memory Catacombs, and Silence Mode.
- AI-style command input with hidden commands:
  - `reveal the dangerous assumption`
  - `brief me`
  - `future duel`
  - `open the below`
- Origin Room easter egg: click the Vanta Lyric mark nine times.
- Mobile and desktop responsive layouts with stable instrument panels.

This is intentionally a front-end cinematic prototype. The architecture implied by the experience can be expanded into real backend services, agent orchestration, graph storage, event streaming, and simulation workers.
